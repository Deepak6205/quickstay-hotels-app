# 🏨 QuickStay — Hotel Booking Web Application

QuickStay is a full-stack hotel booking platform where users can explore hotels, book rooms, make online payments, and hotel owners can manage listings — all in one place.

Built with **React + Node.js + MongoDB**, featuring **Clerk authentication**, **Stripe payments**, and **Cloudinary image uploads**.

Live Demo: https://quickstay-hotels-app.vercel.app

---

## ✨ Features

### 👤 User

- Browse hotels & rooms
- Search by destination
- Book rooms with date selection
- Stripe checkout payment
- View personal bookings
- Authentication with Clerk
- Recent search tracking

### 🏨 Hotel Owner

- Owner dashboard
- Add rooms with multiple images
- Toggle room availability
- View hotel bookings
- Revenue summary

### ⚙️ Platform

- Secure authentication (Clerk)
- Online payments (Stripe)
- Image hosting (Cloudinary)
- Email notifications (Nodemailer)
- REST API backend
- Responsive UI (Tailwind CSS)
